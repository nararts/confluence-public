# Install and update

1. Download the ZIP from the official GitHub release.
2. Extract it before starting Confluence.
3. In Settings > About, use Check for updates. Portable versions supporting the GitHub update channel can download and apply a newer release with a short restart when automatic updates are enabled.

Do not assume every old version supports the current update channel. If updating is unavailable, download the current ZIP manually. Keep a library backup before changing installation formats.

The unsigned MSIX is for packaging review and later trusted signing or Microsoft Store submission. Renaming files or putting them in ZIP does not remove Windows trust requirements. No instructions here require disabling security protection.
