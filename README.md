# Confluence

Personal music player for Windows: a local library, playlist import, synchronized lyrics, configurable appearance, a compact player and floating island.

## Downloads

Download the current Windows release from [confluence-releases](https://github.com/nararts/confluence-releases/releases/latest).

- The ZIP contains the portable Windows application.
- The separately labelled `-unsigned.msix` file is a packaging candidate. It is not a ready-to-install signed public package.
- Availability of streaming tracks depends on their source, access permissions and region. Importing metadata does not grant access to protected audio.
